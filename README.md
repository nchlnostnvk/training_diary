# Дневник тренировок

Простой консольный дневник тренировок, написанный на Python.

## Возможности

- Добавление тренировок с указанием продолжительности.
- Просмотр списка тренировок.
- Подсчёт суммарного времени тренировок.
- Проверка корректности введённого количества минут.
- Завершение работы через команду `exit`.

## Запуск

Требуется установленный Python 3.

Запустите программу командой

```bash
python main.py
```

## Команды

 Команда  Описание 
------
 `add бег 30`  Добавить тренировку «бег» на 30 минут 
 `list`  Вывести список тренировок 
 `total`  Вывести общее время 
 `exit`  Завершить программу
