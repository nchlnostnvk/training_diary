# Дневник тренировок

**Лабораторная работа №4 | Вариант 33**

Консольное приложение на Python для ведения дневника тренировок, подсчёта их общей продолжительности и анализа тренировочной активности.

Проект является продолжением лабораторных работ №2 и №3.

## Функциональность

Программа позволяет:

- Добавлять тренировки с указанием вида и продолжительности.
- Просматривать историю тренировок.
- Подсчитывать общее время тренировок.
- Получать список уникальных видов тренировок.
- Находить виды тренировок, последняя продолжительность которых превышает 30 минут.
- Выводить названия видов тренировок заглавными буквами.
- Получать случайные мотивационные сообщения.
- Просматривать справку по командам.

## Используемые технологии

- Python 3
- Стандартный модуль `random`
- Списки (`list`)
- Словари (`dict`)
- Множества (`set`)
- Генераторы списков (list comprehensions)
- PyTest для автоматического тестирования

## Структуры данных

В лабораторной работе используются три структуры данных:

**Список (`list`)** — хранит историю всех тренировок в виде кортежей:

```python
log = [("бег", 30), ("плавание", 45)]
```

**Словарь (`dict`)** — хранит последнюю указанную продолжительность для каждого вида тренировки:

```python
kinds = {"бег": 30, "плавание": 45}
```

**Множество (`set`)** — хранит уникальные виды тренировок:

```python
kinds_set = {"бег", "плавание"}
```

Для обработки данных используются генераторы списков:

```python
[k for k, m in kinds.items() if m > 30]
[k.upper() for k in kinds]
```

## Автоматическое тестирование

Для проверки корректности функций используется PyTest.

Реализованы четыре теста:

1. `test_add_workout` — проверка добавления тренировки.
2. `test_total_minutes` — проверка подсчёта общего времени.
3. `test_add_kind` — проверка добавления уникальных видов тренировок.
4. `test_long_workouts` — проверка фильтрации тренировок по продолжительности.

Запуск тестов:

```bash
python -m pytest -v
```
