# Дневник тренировок

Простое консольное приложение на Python для учёта тренировок и затраченного на них времени.

## Возможности

- Добавление тренировок с указанием продолжительности.
- Просмотр списка записей.
- Подсчёт общего времени тренировок.
- Проверка корректности введённых данных.
- Защита от повторного добавления тренировок с одинаковым названием.

## Установка и запуск

**Требования:** Python 3.

1. Склонируйте репозиторий или скачайте его исходный код.
2. Откройте папку проекта в терминале.
3. Запустите программу:

   ```bash
   python main.py
   ```

## Использование

После запуска программа принимает команды в консоли.

| Команда | Пример | Описание |
|---|---|---|
| `add <название> <минуты>` | `add бег 30` | Добавить тренировку на 30 минут |
| `list` | `list` | Показать список тренировок |
| `total` | `total` | Показать суммарное время |
| `exit` | `exit` | Завершить программу |

Пример работы:

```text
> add бег 30
Тренировка бег добавлена.
> add силовая тренировка 45
Тренировка силовая тренировка добавлена.
> list
бег, силовая тренировка
> total
Общее время: 75 минут
> exit
```
