# Training Diary — Дневник тренировок

Консольное приложение на Python для учёта тренировок и подсчёта их общей продолжительности.

Проект выполнен в рамках лабораторной работы №3 по программированию.

## Возможности

- Добавление тренировок с указанием вида и продолжительности.
- Просмотр записанных тренировок.
- Подсчёт общего времени тренировок.
- Вывод случайных мотивационных фраз.
- Справка по доступным командам.
- Проверка корректности введённых данных.

## Установка и запуск

**1. Клонировать репозиторий:**

```bash
git clone https://github.com/nchlnostnvk/training_diary.git
```

**2. Перейти в папку проекта:**

```bash
cd training_diary
```

**3. Запустить программу:**

```bash
python main.py
```

Для работы требуется Python 3.10 или новее. Сторонние библиотеки не используются.

## Доступные команды

| Команда | Описание |
|---|---|
| `add <вид> <минуты>` | Добавить тренировку |
| `list` | Показать дневник тренировок |
| `total` | Показать общее время |
| `motivate` | Вывести мотивационную фразу |
| `help` | Показать справку |
| `exit` | Завершить программу |

## Пример использования

```text
> add бег 30
Тренировка бег добавлена.

> add подтягивания 20
Тренировка подтягивания добавлена.

> list
бег — 30 мин, подтягивания — 20 мин

> total
Общее время: 50 минут

> motivate
Каждая тренировка приближает тебя к цели!

> exit
Программа завершена.
```

## Реализованные функции

- `show_help()` — выводит справку по командам.
- `add_workout(log, kind, minutes)` — добавляет тренировку в дневник и возвращает обновлённую строку.
- `total_minutes(current, minutes)` — возвращает суммарное время тренировок.
- `random_motivation()` — возвращает случайную мотивационную фразу.

## Особенности реализации

- Данные о тренировках хранятся в строке.
- Виды тренировок импортируются из собственного модуля `training_data.py`.
- Для обработки пользовательского ввода используется `rsplit()`.
- Для генерации мотивационных фраз используется стандартный модуль `random`.
- Ошибки ввода обрабатываются с помощью `try/except`.
- Данные хранятся в оперативной памяти и не сохраняются после завершения программы.
